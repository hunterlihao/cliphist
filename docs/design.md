# 界面设计说明

## 0. 约束（来自需求）

- 主题：**浅色**，近单色；界面语言：**中文**。
- 运行环境：原生 Win32 + GDI，**不引入 comctl32**（因此没有主题化的按钮/列表/滚动条），
  不用任何自绘位图素材，全部用 GDI 原语现场绘制。
- 性能约束是硬约束：**常驻内存越低越好**。这条直接决定了下面几乎所有选择。

## 1. 取向：单色 + 反相

列表里只有两级：**纸**（`#FFFFFF`）与**墨**（`#0A0A0A`）。选中态不靠颜色，靠**反相**：

> 选中 = 这一行翻成墨底白字。

理由不是审美洁癖，而是功能性的：

- 列表一屏要放十行以上、每行两行文字加一个缩略图。任何"高亮色"在这种密度下都会
  与缩略图里的真实颜色打架，反而看不清"当前选中的是哪一行"；反相是唯一在缩略图
  旁边依然一眼可辨的标记。
- 三类内容（文本/文件/图片）靠**左侧方块里的文字徽标**区分，不靠颜色编码。
  于是整个界面不需要"三色语义系统"，也不需要为色盲用户做第二套方案。

令牌（`src/ui/theme.rs`）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `PAPER` | `#FFFFFF` | 画布 |
| `WELL` | `#F4F4F4` | 顶部搜索条（凹陷面） |
| `INK` / `INK2` / `INK3` | `#0A0A0A` / `#4A4A4A` / `#969696` | 主文字 / 来源进程 / 时间与提示 |
| `RULE` / `RULE_STRONG` | `#E8E8E8` / `#C6C6C6` | 发丝分隔线 / 外框与描边 |
| `SEL_BG` / `SEL_FG` / `SEL_FG2` | `#0A0A0A` / `#FFFFFF` / `#A8A8A8` | 选中行（反相）及其上两级文字 |
| `BADGE_BG` / `BADGE_FG` | `#EAEAEA` / `#606060` | 类型徽标 |
| `WARN` | `#B03E2C` | "未记录"、热键冲突、清空确认 |

## 2. 字体：只在等宽字面上做主张

| 角色 | 字族 | 用法 |
|---|---|---|
| 界面 / 预览 | `Microsoft YaHei UI` → `Segoe UI` | 预览文本、标签、按钮文案 |
| **数据 / 机器值** | `Consolas` | 时间、使用次数、尺寸、文件路径、数据文件路径 |

中文界面在 Windows 上可选的"展示字体"其实只有雅黑一套能看，所以字体主张放在**等宽**上：
凡是机器给出的值一律走等宽，使用次数（`×3`）、图片尺寸（`1920×1080`）、
数据文件路径在列表里都能竖着对齐、逐字符扫读。这是功能，不是风格。

字号（逻辑像素，随 DPI 缩放）：预览 14 / 元信息 12 / 徽标 11 / 等宽 12。

## 3. 几何与度量

| 度量 | 逻辑值 | 说明 |
|---|---|---|
| 弹窗宽度 | 420 | 固定宽度，只在高度上贴合内容 |
| 最大 / 最小高度 | 560 / 140 | 1 条时不摆一大片空白 |
| 搜索条高 | 40 | 系统 `EDIT` 子控件，边框不可见，融进 `WELL` 底色 |
| 行高 | 52 | 两行文字 + 40px 方块 |
| 缩略图/徽标方块 | 40 | 长边 128 的缩略图按等比缩放居中入框 |
| 页脚高 | 26 | 左侧按键提示、右侧条目计数 |
| 圆角 | 4 | 只有"对象"（徽标、圆点）有圆角，"结构"（行、线、面）一律直角 |
| 滚动条 | 3 | 自绘指示条，不响应拖动（滚轮与键盘才是主要交互） |

## 4. 一行的解剖

```
┌──────────────────────────────────────────────────────────────┐
│  ▍┌──────┐  预览文本（单行，超出省略号）                  ●  │  ← ● = 置顶标记
│   │ 文本 │  chrome.exe · 3 分钟前              ×2           │  ← ×N = 使用次数（等宽）
│   └──────┘                                                   │
└──────────────────────────────────────────────────────────────┘
   ↑ 类型徽标（图片行这里是缩略图）    ↑ 元信息：类型补充 · 来源进程 · 相对时间
```

元信息按"类型补充 · 来源进程 · 相对时间"拼接，类型补充只在有意义时出现
（文件显示"3 个文件"、图片显示"1920×1080"，文本没有这一项）。

相对时间分级：刚刚 / N 分钟前 / N 小时前 / 昨天 / N 天前 / 超过 30 天显示本地日期。
日期换算走 `FileTimeToLocalFileTime` + `FileTimeToSystemTime`，而不是自己按 UTC 算 ——
在 UTC+8 的凌晨，自己算会显示成前一天，这类"差一天"的 bug 很难被发现。

## 5. 交互

- **单击即粘贴**（与 Win+V 一致），不要求双击。
- 键盘优先：呼出后焦点直接在搜索框，方向键上下选择，回车粘贴。
  `↑/↓/PgUp/PgDn/Home/End/Enter/Esc/Ctrl+P/Ctrl+D` 由搜索框的子类化过程拦截并转给列表，
  **其余按键（含退格、左右方向键、字母）原样交给 EDIT**，中文输入法因此完全正常。
- 搜索框为空时列表显示全部；输入即筛选；预览无命中才回退到正文搜索（限最近 2000 条、
  单条正文 < 256KB），保证最坏情况可控。
- 点击别处 / 切走即关闭（`WM_ACTIVATE` 的 `WA_INACTIVE`）。
- 空状态：没有历史显示"还没有历史记录"，筛选无结果显示"没有匹配的记录"，都居中且用三级灰。
- 页脚常驻按键提示；暂停记录时右侧计数替换为"已暂停"。

## 6. 设置窗口

一列"标签 + 值"，没有按钮、没有下拉框、没有复选框，只有一个交互模型：

- **布尔行**：点一下切换（开/关、自动粘贴/仅放回剪贴板）。
- **数值行**：点左右两半减小/增大（值文本里用 `◀ ▶` 明示）。
- **热键行**：点一下进入捕获态（值变成"请按下新组合键…"），按下新组合键生效，Esc 取消；
  不带修饰键的组合会被拒绝并给出提示，因为那会抢走用户的普通打字。
- **清空行**：两段式确认（第一次点变成"再点一次确认清空"），避免误触。
- **数据文件行**：显示实际生效路径，点击打开所在目录。

这样做的收益：没有焦点管理、没有 Tab 顺序、没有控件主题依赖，
窗口过程里也没有任何会泵消息的调用（唯一的模态交互 `TrackPopupMenu` 被放在控制器窗口上）。

## 7. 托盘图标

运行时用 GDI 画进 32bpp DIB 再 `CreateIconIndirect`：一张浅色卡片 + 顶部夹子 + 两行文字，
尺寸取 `GetSystemMetrics(SM_CXSMICON)`（随 DPI 变化）。失败时回退系统默认图标。

关键实现细节：**GDI 画像素不会写 alpha 通道**，所以先在整个画布填一个哨兵色（洋红），
画完再按"RGB 是否等于哨兵色"决定透明与否，最后把不透明像素的 alpha 置 255。
直接使用 GDI 输出的 alpha 会得到一张全透明的图标。

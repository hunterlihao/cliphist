# 手工验收清单

前提：在**正常桌面会话**里运行 `dist-portable\ClipHist.exe`（不是服务/无桌面沙箱）。

> 采集侧（文本 / 文件 / 图片能不能真的读进来、去重对不对、缩略图有没有生成）已经在
> 当前环境用 `--log` 诊断日志端到端实测过，证据见
> [测试计划 §4.1](test-plan.md)。下面各条里**还需要手工确认的是交互与粘贴**：
> 热键呼出、单击/回车、粘到别的程序、托盘菜单、多显示器等。

标记：✅ 已在当前环境自动验证 · 🖐 必须手工在桌面会话确认

## A. 启动与常驻

| # | 步骤 | 预期 |
|---|---|---|
| A1 ✅ | 双击 `ClipHist.exe` | 无窗口弹出、无安装过程；托盘出现图标；首次启动弹一次气泡提示热键 |
| A2 ✅ | 任务管理器看进程 | 只有一个 `ClipHist.exe`，私有内存 2~3 MB |
| A3 ✅ | 检查 exe 同目录 | 出现 `data.db`（约 40 KB）；没有 `-wal`/`-shm`/`-journal` 残留 |
| A4 🖐 | 托盘图标外观 | 是一张浅色卡片 + 夹子形状，不是系统默认图标（若为默认图标说明自绘失败，属降级而非崩溃） |
| A5 🖐 | 鼠标悬停托盘图标 | 提示为"剪贴板历史 · Alt+V" |
| A6 🖐 | 再次双击 exe | **不产生第二个进程**，而是把已有实例的历史列表呼出 |

## B. 文本

| # | 步骤 | 预期 |
|---|---|---|
| B1 🖐 | 记事本里复制一段中英混排 + emoji 文本，按 Alt+V | 列表顶部出现该条，预览为单行、空白已折叠 |
| B2 🖐 | 把焦点切回记事本，再按 Alt+V 回车 | 文本被粘贴到记事本光标处 |
| B3 🖐 | 复制带换行的多行文本 | 预览为单行（换行折叠成空格），粘回后换行**原样保留** |
| B4 🖐 | 复制超过 2 MB 的文本（例如把一个大日志全选复制） | 弹气泡"未记录：内容过大"；列表不新增条目；剪贴板内容不受影响 |
| B5 🖐 | 连续两次复制完全相同的内容 | 只有一条记录，右侧使用次数 `×2`，时间刷新 |
| B6 🖐 | 复制一段含 `%` 和 `_` 的文本，然后在搜索框输入 `%` | 只匹配真正包含 `%` 的条目（LIKE 通配符已转义，不能变成"匹配全部"） |
| B7 🖐 | 搜索一个只出现在长文本中间的关键字 | 能搜到（预览无命中时回退正文搜索） |

## C. 文件（"常用文件"）

| # | 步骤 | 预期 |
|---|---|---|
| C1 🖐 | 资源管理器里选中 3 个文件复制，按 Alt+V | 新增一条"文件"记录，预览形如 `a.txt、b.txt 等 3 项`，元信息显示"3 个文件" |
| C2 🖐 | 清空剪贴板（随便复制一段文本），再回到列表选中该文件条目回车，然后到另一个文件夹 Ctrl+V | 粘出 3 个**副本**；原位置的 3 个文件仍然存在（绝不能被"移动"走） |
| C3 🖐 | 复制一个文件夹 | 记录显示目录名并以 `\` 结尾；粘回时整个文件夹被复制 |
| C4 🖐 | 复制**图片文件**（.png） | 记录是"文件"而不是"图片"（`CF_HDROP` 优先于 `CF_DIB`）——这是本项目刻意保证的行为 |
| C5 🖐 | 复制路径超过 260 字符的文件 | 能正常记录与粘回（`\\?\` 前缀路径不截断） |
| C6 🖐 | 右键该条目 | 菜单含 置顶 / 删除 / 打开 / 打开所在文件夹 / 复制路径；点"打开"能启动关联程序，"打开所在文件夹"能选中该文件 |
| C7 🖐 | 对某条按 Ctrl+P 置顶 | 该条固定到列表最前；重启程序后仍在最前 |

## D. 图片

| # | 步骤 | 预期 |
|---|---|---|
| D1 🖐 | `Win+Shift+S` 截一张带文字的图，按 Alt+V | 新增"图片"记录，左侧显示**缩略图**（有清晰缩放，不是最近邻锯齿） |
| D2 🖐 | 选中该条回车，到画图里 Ctrl+V | 图片出现在画图里 |
| D3 🖐 | 同上，到 Word / 浏览器里 Ctrl+V | 图片粘入 |

| D5 🖐 | 复制一张 4K 全屏截图 | 记录成功，缩略图正常；`data.db` 增长有限（入库前长边已限制到 2560） |
| D6 🖐 | 复制一张超大图（如 8K 拼图，超过 1200 万像素） | 弹气泡"未记录：图片像素过多"，程序不卡顿 |

|---|---|---|

## M. 粘贴队列（0.2.0 起）

| 步骤 | 预期 |
|---|---|
| 复制三段不同文本 → `Alt+V` 呼出 → 依次在三条上按 `空格` | 标记区出现 ①②③；再按一次空格可移出 |
| 切到目标输入框（勿点我们的窗口），按一次 `Ctrl+Alt+V` 并松手 | **第一次就应直接粘出第一条**（不会只进剪贴板） |
| 再按 `Ctrl+Alt+V` | 粘出第二条；页脚/状态显示"队列 N 条"递减 |
| 粘完最后一条后再按 | 气泡提示"队列是空的" |
| 排 3 条后切到输入框按 `Ctrl+Shift+Enter` | 剪贴板变成三段合并的多行文本（不自动粘贴） |
| 队列里只放图片后按 `Ctrl+Shift+Enter` | 气泡提示"没有可合并的内容" |

**已知坑（0.3.3/0.3.4 修过，回归时务必覆盖）**
- 粘贴目标必须是**按键那一刻**的前台窗口，不能沿用开列表时的句柄（0.3.3）。
- 注入 `Ctrl+V` 前必须等物理修饰键松开，否则会被识别成 `Ctrl+Alt+V`（0.3.4）。

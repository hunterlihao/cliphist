剪贴板历史（ClipHist）· 便携版
================================

一、怎么用
----------
1. 双击 ClipHist.exe：先播一段开场动画（约 0.8 秒），随后**主窗口在屏幕正中打开**。
2. 主窗口是"可以待着"的窗口：单击选中、双击或回车才粘贴；✕ / Esc 关闭。
3. 平时更常用的是热键：按 Alt+V，在光标处弹出浮动列表，单击即粘贴，Esc 关闭。
4. 单击托盘图标 = 打开居中的主窗口（再点一次收起）。
5. 输入关键字即时筛选（先搜预览，没命中再搜正文）。

列表里的按键：
  ↑ / ↓          选择
  Enter          粘贴到原窗口
  Shift+Enter    只放回剪贴板，不自动粘贴
  Ctrl+1 ~ 9     直接粘贴第 N 条
  空格           加入 / 移出粘贴队列（标记区显示 ①②③）
  Ctrl+Alt+V     粘贴队列里的下一条
  Ctrl+P         置顶 / 取消置顶（置顶＝常用，不会被自动清理）
  Ctrl+D         删除选中那条
  右键           置顶 / 删除 / 打开 / 打开所在文件夹 / 复制路径
  Esc            关闭
  滚轮           翻页

托盘图标右键：
  打开主窗口（居中） / 浮动列表（光标处） / 继续或暂停记录 / 设置… /
  开机自启 / 清空历史（保留置顶） / 退出

二、粘贴队列（连续粘贴多段内容）
--------------------------------
场景：填一张表单，要把"姓名、电话、地址"三段分别粘到三个输入框；或者把几段材料
一段一段搬进另一篇文档。以前每粘一段都要重新打开历史找一次，现在：

  1. 打开列表，选中第一段 → 按空格（标记区出现 ①）
  2. 选中第二段 → 空格（②），第三段 → 空格（③）
  3. 切到目标窗口，光标放到第一个输入框，按 Ctrl+Alt+V → 粘出 ①
  4. Tab 到下一个框，再按 Ctrl+Alt+V → 粘出 ②，以此类推

队列用完自动清空；页脚会显示"队列 N 条"。再按一次空格可把某条移出队列。
队列只存在内存里（退出程序即丢），不会写进历史库。

三、记录什么
------------
* 文本：任何程序里复制的文字。
* 文件：在资源管理器里复制的文件或文件夹（可整批粘回另一个文件夹）。
  为避免误删，粘回时一律按"复制"处理，绝不会把原文件移走。
* 图片：截图（Win+Shift+S）或网页/画图里复制的图片，带缩略图。

不会记录的内容：
* 密码管理器明确标记"请勿记录"的剪贴板内容。
* 超过大小上限的条目（默认：单条 2MB，图片 1200 万像素）。
  这种情况下会弹一个托盘气泡告诉你"未记录"，而不是悄悄丢掉。

四、设置窗口
------------
托盘右键 → 设置…（窗口在屏幕正中弹出）。每一行点一下就切换，或调数值：
* 数值行（最多保留 / 保留天数 / 单条上限 / 图片总量）：点左侧 ◀ 减小，点右侧 ▶ 增大，
  点中间的文字不会误改。
* 弹出热键：点这一行，然后按下新的组合键（必须带 Ctrl/Alt/Shift/Win）。
  如果该组合已被系统或其他程序占用，页脚会直接告诉你"不可用"，不会假装成功。
* 启动动画：可关。开机自启时一律不播（那时候你不在等）。
* 数据文件：显示实际生效的路径，点一下打开所在文件夹。
* 清空历史：需要点两次确认。

五、数据在哪
------------
程序同目录下的 data.db（单文件，SQLite）。整个文件夹拷到 U 盘或另一台电脑，
历史与设置会一起跟过去。

如果程序目录不可写（例如放进了 C:\Program Files），会自动改存到
%LOCALAPPDATA%\ClipHist\data.db，并在设置窗口里显示实际路径。

六、内存占用
------------
设计目标是最小常驻内存：
* 列表只加载每条的预览（前 200 字符），正文与图片按需读取、用完即释放，
  所以历史有 1000 条还是 10 条，常驻内存几乎一样。
* 缩略图缓存上限 24 张，超出按最久未用淘汰。
* data.db 的页缓存限制在 512KB，并关闭内存映射。
* 图片编码、缩略图生成、写库、清理全部在后台线程，不占用界面线程。

可以用 scripts\measure-memory.ps1 自己量（脚本会给出私有内存的峰值与判定）。

七、已知限制
------------
* 只支持 Windows 10 1809 及以上 / Windows 11。
* 如果目标窗口以管理员权限运行，本程序无法把按键送进去（Windows 的 UIPI 限制）。
  此时内容仍会放进剪贴板，会弹气泡提示你手动按 Ctrl+V。
* 默认热键是 Alt+V；如果冲突，在设置里改成别的组合（例如 Alt+空格）。
* 托盘图标创建失败时程序不会退出：热键与主窗口照常可用，列表页脚显示"托盘不可用"。
* 系统自带的 Win+V 历史与本程序互不影响，可以同时开。
* data.db 是明文存储的。剪贴板里可能有密码、验证码，请勿分享该文件，需要时用"清空历史"。
* 开机自启写在 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 下的 ClipHist 值。

八、卸载
--------
删除整个文件夹即可。如果开过开机自启，请在设置里关掉（或删掉注册表里
HKCU\...\Run 下的 ClipHist 值），否则开机会尝试启动一个已不存在的程序。
